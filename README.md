# VoltRelay Energy – EV Battery Swapping Network Analysis

## Project Overview

This project analyzes the operational performance of **VoltRelay Energy**, an EV battery-swapping network.

Despite increasing swap volumes and revenue, the business faces challenges related to swap failures, rider experience, battery availability, customer retention, and operational efficiency.

The objective of this project is to transform raw operational data into actionable business insights and recommendations that can help VoltRelay improve reliability, customer satisfaction, and sustainable growth.

## Business Problem

VoltRelay needs to understand:

- Why are battery-swapping attempts failing?
- Which cities and stations have operational challenges?
- How does battery health affect network performance?
- What factors influence rider experience and repeat usage?
- How can the business improve operational efficiency and unit economics?

## Project Objectives

1. Evaluate overall network performance.
2. Identify major swap failure patterns.
3. Analyze city-wise and station-wise performance.
4. Investigate battery health and equipment performance.
5. Understand rider activity and customer support trends.
6. Develop data-driven business recommendations.

## Datasets Used

The analysis uses eight interconnected datasets:

| Dataset | Description |
|---|---|
| swap_events | Battery swap transactions and outcomes |
| stations | Station information and locations |
| station_hourly_status | Hourly station operations |
| batteries | Battery health and technical information |
| riders | Rider demographics and activity |
| support_tickets | Customer complaints and support |
| fleet_partners | Fleet partner information |
| city_daily_context | City-level operational conditions |

## Analytical Approach

The project follows a structured data analytics workflow:

1. **Data Understanding:** Explore dataset structure, dimensions, and variables.
2. **Data Cleaning:** Handle missing values, duplicates, inconsistent records, and data-quality issues.
3. **Data Validation:** Check primary keys, foreign keys, and relationships between datasets.
4. **Exploratory Data Analysis (EDA):** Identify trends, distributions, and performance patterns.
5. **Business Analysis:** Evaluate failures, station performance, rider behaviour, battery health, and operational economics.
